# Sky Putt — review build

Playable review build of **Sky Putt** (3D mini golf across 14 floating worlds) for the MediaCube / YouTube Playables submission.

- `/` — the submitted build (outside YouTube the Playables SDK is a no-op: ads appear as labelled placeholders, saves are per-session)
- `/demo/` — the same build with every course, cosmetic and mode unlocked, for reviewers who want to jump ahead

Not the source of truth; the game is built from a private source tree.
